# 📒 Agenda de Contatos

Uma aplicação simples de linha de comando para cadastrar e gerenciar contatos. Os dados são armazenados localmente em um banco de dados SQLite.

## ✨ Funcionalidades

- ➕ Adicionar contatos com nome e telefone
- 📋 Listar todos os contatos cadastrados
- ✏️ Atualizar o telefone de um contato
- 🗑️ Excluir contatos pelo ID
- 💾 Salvar os dados em um banco SQLite local

## 🛠️ Tecnologias

- 🐍 Python 3
- 🗄️ SQLite, usando o módulo `sqlite3` da biblioteca padrão do Python

## 🚀 Como executar

1. Instale o [Python 3](https://www.python.org/downloads/).
2. Salve o código em um arquivo chamado `agenda.py`.
3. Abra o terminal na pasta do arquivo.
4. Execute:

```bash
python agenda.py
